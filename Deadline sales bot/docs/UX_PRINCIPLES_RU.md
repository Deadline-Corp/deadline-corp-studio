# Сквозные UX-принципы панели DEADLINE

Единый свод правил, которым следует ВЕСЬ интерфейс админ-панели (и Claude, и Nick при
любых правках UI). Цель: чтобы пользователь зашёл — и всё было интуитивно понятно,
удобно, красиво, без путаницы. Зафиксировано 2026-06-19 по решению владельца.

> Главная мысль продукта: **«Бот — первая линия продаж, человек — closer.»**
> Бот сам общается с лидами; человек подключается только там, где нужен. Интерфейс
> должен всё время это показывать.

---

## 1. Прозрачность бота — ВЕЗДЕ
Пользователь всегда должен видеть, **что бот делает и что решил сам** — это даёт доверие.
- В каждом списке лидов — бейдж «кто ведёт»: 🤖 **бот ведёт** / 🟠 **ждёт тебя** / 👤 **ты на связи**.
- В карточке лида — блоки «🤖 План бота» (что планирует и когда) и «🤖 Решения бота»
  (что сделал и ПОЧЕМУ) всегда доступны.
- Где уместно — короткая «лента бота»: что он сделал сам (ответил / забронировал / дожал).
- Никогда не прятать автономные действия бота: если он что-то сделал за человека — это видно.

## 2. Один объект «лид» — одно главное действие
- Карточка лида ОДНА на все вью (Переписки / Воронка / Канвас / Задачи) — открывается
  одинаково из любого места.
- На каждом объекте — **одно основное действие** (крупная кнопка), остальное под «···»/«Ещё».
- Не плодить разные способы сделать одно и то же без причины.

## 3. Один язык цвета во всём приложении
Одни и те же сущности — одинаковый цвет на всех экранах:
- **Стадии воронки** — фиксированный цвет-маркер (точка/тон), одинаковый в воронке, карточке, аналитике.
- **Температура лида** — 🧊 cold / 🌤 warm / 🔥 hot / 🚀 ready / 🤝 client / ❄️ frozen — единые цвета.
- **Каналы** — Telegram / WhatsApp / Сайт / Instagram — единые иконка+цвет.
- Семантика: успех = зелёный, внимание = оранжевый, опасно = красный, инфо = синий. Бренд-акцент — фиолет, точечно.

## 4. Прогрессивное раскрытие (не пугать сложностью)
- Показывать 3–4 частых действия; редкое/продвинутое — прятать под «Ещё» / раскрывашку «Продвинутое».
- Пример: в «Мозге» простые правила сверху, полный системный промпт — под «Продвинутое».
- Плотность данных — по необходимости, без визуального шума.

## 5. Простой русский + подсказка на каждом экране
- Человеческие подписи, без жаргона («Не сложилось», а не «lost»; «Созвон», а не «booking»).
- На каждом экране — одна строка «что это и что тут делать» (HintBar), которую можно скрыть.
- Значки «?» (Help) у неочевидных функций.

## 6. Обратимо, а не разрушительно
- «Убрать лид» = в архив (обратимо, виден в экспорте/архиве), НЕ удаление. Везде, где
  что-то «исчезает», — должна быть «↩ Вернуть» или восстановление из архива.
- Деструктив — только с явным подтверждением (правило never-delete всего проекта).

## 7. Мгновенная обратная связь (само обновляется)
- После любого действия (стадия / архив / ответ / задача) списки и счётчики обновляются
  **сразу**, без ожидания и без ручного «обновить» (шина событий `emitLeadsChanged`).
- Действие должно давать видимый результат немедленно (оптимистичный UI + тост).

## 8. Удобный вход в действие (минимум кликов)
- Частые операции — в один клик прямо на объекте (пример: ✕ «убрать» на карточке/строке,
  «✅ Отправить» на предложенном ботом ответе). Без «ОК», спрятанных в глубине.

## 9. Мобайл — равноправно
- С телефона так же удобно: выезжающее меню, крупные зоны нажатия, одноколоночные раскладки.

## 10. Единый визуальный язык (премиальный светлый)
- Светлая тема (белый + холодный slate, бренд-фиолет точечно), мягкие тени, крупные радиусы.
  Тёмная — равноценная альтернатива по тумблеру. Эмодзи-глифы в плитках как часть айдентики.

## Зафиксированные решения (2026-06-19)
- **Стартовый экран = «Карта системы» (канвас).** Оставляем как есть — НЕ заменяем на «Сегодня».
  Идея «Сегодня» (приоритетный кокпит) — отложена, не делаем сейчас.
- **Делаем:** прозрачность бота везде (п.1), запись этих принципов (этот файл), карточку лида
  разложить по зонам (см. ниже).

## Бэклог по этим принципам
- **Карточка лида по зонам** (когда `ConversationDrawer.tsx` будет свободен от параллельной
  правки): действия сгруппировать в понятные зоны —
  **Диалог** (ответить / взять на себя / предложить ответ) ·
  **Сделка** (стадия / 🗑 убрать / сумма) ·
  **Запланировать** (задача / созвон / дожать) ·
  **Контекст** (поля / история / решения бота — свёрнуто).
  Показывать частое, остальное под «Ещё».
- Единый язык цвета по всем экранам (п.3) — довести до конца.
- Песочница «Проверить бота» в «Мозге» (написать как клиент → увидеть ответ бота).
- Аналитика: 3 простых ответа сверху (сколько лидов и откуда / где застревают / бот сам vs человек).
