# Фича: Панель и доступы

## Что делает
Веб-панель (admin/ui) — все переписки, карточка лида, воронка, задачи, календарь,
мозг, настройки, аналитика. Доступ по ролям (owner / менеджер).

## Файлы кода
- Фронт: `admin-ui/src/` (Vite/React SPA), отдаётся на `…/admin/ui`.
  - `pages/Inbox.tsx` — список «Переписки».
  - `components/ConversationDrawer.tsx` — карточка лида.
  - `pages/Funnel.tsx`, `Tasks.tsx`, `Calendar.tsx`, `Brain.tsx`, `Channels.tsx`, `Settings.tsx`.
- Бэк: `admin_api.py` — все `/admin/api/*`, авторизация `_verify_owner` / `_verify_member`.

## Доступы
- **Owner** — токен `TRAINING_AUTH_TOKEN` (env). Полный доступ, включая разрушительные
  действия (удаление KB, чистка фантомов, дедуп).
- **Менеджер/партнёр** — именной токен `mgr_…`, создаётся `POST /admin/api/team {name}`
  (owner). Роль `manager` = `_verify_member` (без owner-destructive). Партнёр вводит
  токен на экране входа `…/admin/ui`. Список — `GET /team`; отключить — `POST /team/{id}/toggle`.
  Текущий партнёрский токен — см. память проекта (поздно-21).

## Карточка лида (ConversationDrawer)
- Сворачиваемые блоки (чтобы видеть переписку): ⚙️ Действия (верх, свёрнут по умолч.),
  «🤖 Система предлагает ответить» (черновик ✅/🔄/🚫), «✍️ Ответить вручную» (свёрнут).
- Имя: `_wa_display_name` — имя → телефон → `+номер` → «WhatsApp •хвост4». Для @lid-лидов
  телефон подтягивается через WAHA LID API (см. whatsapp-connector.md) → видно реальный номер.
- Кнопки: Взять на себя, Сменить стадию, Пинок (дожим-черновик), Задача, Что делать,
  Назначить созвон (datetime), Регулярный, Назначить на сотрудника, Ведёт система.

## Грабли
- Список «Переписки» не всегда авто-обновляется в реал-тайме → Ctrl+F5.
- Новые рекламные лиды — под «WhatsApp •хвост», если телефон ещё не разрезолвлен.

## Как проверить
- Вход: `…/admin/ui` + токен.
- Создать партнёра: `POST /admin/api/team {"name":"Партнёр"}` (Bearer owner-токен).
