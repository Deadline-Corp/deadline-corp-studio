# Фича: Автопилот + умное авто-ведение (мозг)

## Что делает
Решает, что система делает с входящими WhatsApp: показать черновик на одобрение,
или отвечать самой. Плюс «мозг» — сам двигает воронку, бронирует созвон и сигналит
владельцу по смыслу переписки (в т.ч. из ручных реплик оператора).

## Файлы кода
- `services/conversation_brain.py` — `analyze_and_advance` (стадия/бронь/сигнал/освежение
  черновика), `sweep_recent` (периодическая проверка из крона).
- `main.py` — `_wa_route_answer` (режим: держать черновик / отвечать),
  `_brain_for_wa_peer` (запуск мозга по входящему лида), `_record_wa_operator_message`
  (мозг по ручной реплике). Ветка движка ответа по `WA_BRAIN` (main.py ~1755).
- `services/cron.py` — `sweep_recent` каждые ~10 мин.
- `services/bot_settings.py` — флаги `wa_observe_only`, `wa_draft_mode`.

## Режимы (Каналы → WhatsApp)
- **👀 Наблюдение** (`wa_observe_only=true`) — система готовит ответ, клиенту НЕ шлёт;
  оператор одобряет ✅ в карточке. Дефолт, безопасно.
- **📝 Черновик в Telegram** (`wa_draft_mode=true`) — черновик в TG на одобрение.
- **🤖 Автопилот** (оба false) — система сама отвечает каждому новому лиду. «На ночь».
- **Per-conv** «🤖 Ведёт система» (`Conversation.wa_autonomous`) — override для одного диалога.

## Флаг WA_BRAIN (включается вручную)
`WA_BRAIN=1` (Railway env) включает: умное авто-ведение (`_brain_for_wa_peer` + sweep) +
фоновое освежение черновиков + **движок ответа = `wa_drafts`** (хороший, см.
[reply-engine-drafts.md](reply-engine-drafts.md)). `WA_BRAIN` пусто → всё выкл, ответы
прежним движком, черновик по кнопке.

## Что делает мозг (analyze_and_advance)
Один LLM-вызов (Gemini, JSON) по переписке:
1. **Стадия** — двигает ТОЛЬКО вперёд (`_FORWARD`), по смыслу.
2. **Бронь созвона** — если согласовано конкретное время → `booked_call_at` + стадия
   `on_call` + напоминания (те же примитивы, что ручная бронь). Дедуп ±10 мин.
3. **Сигнал владельцу** в Telegram, если лид явно просит человека.
4. **Освежение черновика** — генерит предложенный ответ в фоне (НЕ в GET карточки).
Запускается: по входящему лида, по ручной реплике оператора, периодически (cron,
только диалоги с новыми сообщениями — `brain_last_count`).

## Грабли
- `conversation_detail` (карточка) НЕ делает LLM — иначе поллинг вешает пул. Черновик
  освежает мозг в фоне.
- Полный автопилот шлёт реальным клиентам — включать осознанно. Аварийный стоп:
  снять `WA_BRAIN` или `WA_WEBHOOK_PAUSE=1`.

## Как проверить
- Логи: `[<conv>] brain(bg): {'stage':…, 'booked':…, 'signaled':…, 'draft':True}`.
- Ручной прогон: `POST /admin/api/whatsapp/brain-sweep`.
