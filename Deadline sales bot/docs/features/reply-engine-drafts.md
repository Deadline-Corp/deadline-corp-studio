# Фича: Движок ответов и черновики

## Что делает
Генерирует «лучший следующий ответ» лиду: выясни задачу проекта → дай «от $X» →
веди на созвон. Тёплое первое сообщение с рассказом о Deadline. Опирается на базу
знаний (RAG). Это и предлагаемые черновики (одобряешь), и автопилот-ответы.

## Персона и язык (ВАЖНО)
- Бот = ГОЛОС студии, говорит «МЫ» (мы делаем, у нас был кейс). НЕ представляется
  ботом/AI/«свести вас с командой». На прямой «ты бот?» — честно (роль: собрать бриф).
- **Язык лида**: отвечает на ТОМ ЖЕ языке (англ→англ, рус→рус) — зеркалит последнее
  сообщение лида. (Раньше форсил русский — был баг.)
- **Оффер рекламы** (`bot_settings.wa_active_offer`, Каналы→WhatsApp): первый ответ
  лиду с рекламы — в КОНТЕКСТЕ оффера, своими словами.

## ЕДИНОЕ поле ответа (UI)
В карточке ОДНО поле ответа (не два): предложка системы сразу в редактируемом поле —
менеджер меняет / очищает / пишет своё → «✅ Отправить». Кнопки: «🤖 Предложить»
(сгенерить), «🚫 Очистить», «🤖 Ведёт система». Send: если есть черновик WhatsApp →
`/wa-draft send` (чистит черновик), иначе `/reply` (operator-reply, для всех каналов).
`ConversationDrawer.sendReply`.

## Файлы кода
- `services/wa_drafts.py` — ядро:
  - `_prompt(name, stage, dialog, kb)` — промпт; на первом контакте (нет «Мы:») —
    тёплое представление + вопрос; иначе по сути. Цены зашиты.
  - `_kb_context(query)` — RAG (`db.vector.similarity_search`) → «ФАКТЫ О КОМПАНИИ».
  - `_clean_draft` — снять кавычки, отбраковать эхо-промпта (англо-маркеры).
  - `generate_for_conv` (ставит pending_wa_draft), `generate_reply_text` (только текст,
    для автопилота), `is_stale`/`refresh_if_stale` (свежесть по `based_on_count`).
- `admin_api.py`:
  - `/conversations/{id}/suggest-reply` — кнопка «Предложить ответ» / «Переформулировать».
  - `/whatsapp/prepare-drafts` — пакетно подготовить ответы всем активным лидам
    (фон, `exclude_phones`).
  - `/whatsapp/simulate-lead` — «🔮 что система ответит новому лиду» (тест, не шлёт).

## Логика ответа
1. Задача неясна → 1 уточняющий вопрос.
2. Тип проекта понятен → «от $X» (лендинг $300 / магазин $700 / бот $300 / Mini App
   $500 / AI $300) + предложить созвон.
3. Лид сам просит звонок → согласиться, уточнить время (бронь ставит мозг).
Точную сумму НЕ называет. Тон тёплый, на «вы», 2-4 предложения, живой язык.

## Цены
Зашиты в `wa_drafts._prompt` И в `prompts.py` (#ЦЕНЫ). Менять — в обоих местах.

## Свежесть черновика
`based_on_count` (число реплик на момент генерации). Если лид/оператор написали
позже — черновик `stale` → мозг/панель перегенерят под последнюю переписку.

## Грабли
- `max_tokens=2048` (было 1200 — gemini-2.5 тратит часть на thinking → обрывало ответ).
- Симуляция на «оружейную» тему (баллистика) — модель осторожничает; на нормальных
  лидах (сайт/бот) ответы отличные.

## Как проверить
- Каналы → «🔮 Что бот ответит новому лиду» — вписать сообщение.
- `POST /admin/api/whatsapp/simulate-lead {message}` → reply.
